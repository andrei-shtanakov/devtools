# Verification-потомок исполняет только S8 — план (devtools#384)

**Spec:** `docs/superpowers/specs/2026-09-24-verification-child-s8-only-design.md`
— **не согласована на момент написания плана**; Task 0 это фиксирует.

**Tech Stack:** Python 3.12, `uv run --frozen pytest -q`, ветка → PR → ревью.

## Global Constraints

- Родитель не трогается ни в одном сценарии — проверяется байтами.
- Пересмотр D3 (страж меняет предикат) — часть контракта, а не деталь:
  доказывается тестом, что сила стража на исторических прогонах не упала.
- Коммиты по-русски, трейлеры `Epic: eco.dark-factory` и `Co-Authored-By`.

### Task 0: Согласование спеки (решение владельца)

- [ ] **Step 1** — D1, **D1a**, D2–D4. Ключевое к согласованию: потомок
  наследует `authoring` родителя, а исключение из стража даёт **полный
  предикат §2a** — `remediated_by` непуст И родитель читается И его
  статус `merged_unverified` И `merge` завершён со `source ==
  remediated_by`. Формулировка «работа по авторингу ещё возможна» из
  первой редакции ОТВЕРГНУТА: по ней двенадцать исторических прогонов с
  завершённым `merge` получили бы перезапуск S8. Терминальность потомка
  сохраняется. Без согласования код не начинается.

### Task 2: Страж меняет предикат

- [ ] **Step 1: Failing test** — `resume` потомка после нетерминального
  отказа НЕ отказывает и исполняет только S8; в журнале нет `author`,
  `create_draft_pr`, `merge`.
- [ ] **Step 2: Failing tests (негативная половина)** — сила стража не
  упала. Обязательный случай — **исторический legacy-леджер С
  завершённым `merge`** (таких в `out/governance-runs` двенадцать): он
  НЕ получает S8-повтор, потому что `remediated_by` у него пуст. Плюс
  три fail-closed случая границы: `merge` без `source`; `source` не
  равен `remediated_by`; родитель нечитаем либо не `merged_unverified`.
- [ ] **Step 3: Реализация** — предикат допуска: `remediated_by` непуст
  И родитель читается И его статус `merged_unverified` И `merge`
  завершён со `source == remediated_by`. НЕ «legacy и merge не
  завершён»: по нему двенадцать исторических прогонов получили бы
  перезапуск S8.
- [ ] **Step 4: Run + Commit.**
