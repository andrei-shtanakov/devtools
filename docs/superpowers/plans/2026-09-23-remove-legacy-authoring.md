  умолчание `"legacy"` остаются (D2).

### Задачи 1–3 — вторая редакция (2026-09-23)

Первая редакция ставила страж resume первым: «страж пишется, пока удаляемый
код ещё на месте, — иначе его нечем проверить на красном». Довод верен и
сохранён, но порядок из него не следовал. Страж делает прежний путь
недостижимым через `resume`, и **50 тестов краснеют в тот же коммит** — набор
перестаёт быть зелёным ровно там, где план обещал обратное. Измерение
объёма (спека §6): снятие кортежа роняет **130 тестов из 234**, и по первому
разбору **половина из них сторожит код, который переживёт всю задачу**.

Отсюда три поставки вместо шести задач. Три PR — **структура работы, а не
разрешение на три платных круга ревью**: бюджет подтверждает владелец
отдельно.
