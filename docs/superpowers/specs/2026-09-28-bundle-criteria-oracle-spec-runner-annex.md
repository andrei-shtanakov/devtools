# Приложение к заявке spec-runner: механизм измерения `criteria-closure/v1`

Дата: 2026-09-28. Статус: **предложение соседу**, не норма devtools (rev 8).
Основание — спека `2026-09-28-bundle-criteria-oracle-design.md` §4 (гарантии
G0, G1, G3, G6; статусы; наблюдаемые поля; rev 8). Владелец механизма — spec-runner: он
вправе реализовать гарантии иначе, если ответ несёт поля §4.3 и выполняет §4.1.
devtools проверяет только контракт.

С rev 7 контракт — **прослеживаемость** (`traced`), без синтетического продукта:
ни патчей, ни мутантов, ни базы. История отказа от причинного подтверждения —
спека §4.4 и §10.

## M0. Окружение

Свежий клон репо-владельца на `product_sha`; `uv sync --frozen` из клона (общий
кэш uv — намеренно). `PYTEST_ADDOPTS` и прочие `PYTEST_*` вызова очищаются;
конфигурация pytest репо — часть продукта. Импортируемый продукт — из продуктовых
корней клона (иначе `error: foreign-import`). Продуктовые корни — исходные файлы,
которым соответствуют файлы колеса на `product_sha` (через `RECORD` по sha256);
файл колеса без пары — `error: product-roots-unknown`.

## M1. Сбор и селекторы

`pytest --collect-only` всего набора — авторитетное множество; селектор →
определение (файл + qualname) → токены по §1.4 спеки; множество селекторов BEH —
все собранные элементы с его токеном.

## M2. Исполнение продукта в процессе (G0)

coverage.py с динамическими контекстами (`--cov-context=test`); в расчёт идут
только строки контекста `|run` **внутри тел функций и методов** продуктовых
корней (по AST: не модульный уровень, не тела классов — они исполняются при
импорте, в том числе ленивом внутри теста). Запуски дочерних процессов в
фазе `call` пишутся хуком на `subprocess.Popen`/`os.posix_spawn`/`os.exec*`;
селектор без строк продукта в процессе, но с дочерним процессом —
`subprocess-only`. Замер (i5/#171): 21 селектор, дочерних процессов 0; покрытие
с контекстами по всему набору devtools — 12,9 мин (+4 %).

## M3. Зелёный без наблюдённой флейкости (G3)

Каждый селектор BEH дважды подряд на `product_sha`; оба раза `passed` в фазе
`call`. Расхождение — `nondeterministic`; не `passed` — `not-passed`.

## M4. Ключ измерения (G6)

`content_sha256` — хэш содержимого продуктовых корней и тестовых файлов; один
валидный ответ на `(bundle_pin, content_sha256)` (повтор запрещает devtools,
spec-runner только отдаёт хэш в ответе).
