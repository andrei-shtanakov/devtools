# Приложение к заявке spec-runner: механизм измерения `criteria-closure/v1`

Дата: 2026-09-28. Статус: **предложение соседу**, не норма devtools (rev 5).
Основание — спека `2026-09-28-bundle-criteria-oracle-design.md` §4 (гарантии
G0–G6, род BEH, наблюдаемые поля). Владелец механизма — spec-runner: он вправе
реализовать гарантии иначе, если ответ несёт поля §4.3 и выполняет §4.1–4.2.
devtools проверяет только контракт.

Ниже — реализация, прототип которой прошёл пять замеров на честном воркстриме
devtools i5/#171 (скрипты прототипа: `cov_step.py`, `mutator.py`, `mutplug.py`,
`v4.py`, `v5.py` — dev-скретч, в заявку прикладываются описанием, не кодом).

## M0. Окружение

Свежий клон репо-владельца на `product_sha`; `uv sync --frozen` из клона (общий
кэш uv — намеренно). `PYTEST_ADDOPTS` и прочие `PYTEST_*` вызова очищаются;
конфигурация pytest репо — часть продукта. Импортируемый продукт — из продуктовых
корней клона (иначе `error: foreign-import`). Продуктовые корни — исходные файлы,
которым соответствуют файлы колеса на `product_sha` (через `RECORD` по sha256);
файл колеса без пары — `error: product-roots-unknown`.

## M1. Сбор и покрытие по фазе

`pytest --collect-only` всего набора — авторитетное множество; селектор →
определение (файл + qualname) → токены по §1.4 спеки. Покрытие — coverage.py с
динамическими контекстами по тесту (`--cov-context=test`: `<node>|setup`,
`|run`, `|teardown`); в кандидаты идут только строки контекста `|run` в
продуктовых корнях. Замер: весь набор devtools — 12,9 мин (+4 %).

## M2. Классификация «обнаружил тест» (G2)

Хук `pytest_runtest_makereport` (фаза `call`): падение засчитывается, если тип
`AssertionError`, `Failed` (`pytest.fail`, «DID NOT RAISE») и файл кадра, где
исключение брошено, — собранный тестовый файл, `conftest.py`, модуль плагина
pytest (`config.pluginmanager`) или тестового хелпера (модуль под тестовыми
путями). Всё прочее — падение продукта, не обнаружение.

## M3. База изменения

Для BEH: дифф каждого коммита из `task_commits` против первого родителя
(`git diff -U0`), куски продуктовых файлов; откатить на копии `product_sha`
только куски, где хотя бы одна изменённая/добавленная строка исполнена
селекторами BEH в `|run`. Прогнать селекторы: падение по M2 у ≥1 селектора →
`change`; повтор K = 2 (база/HEAD чередованием) с единогласием. Файл не
разбирается/не импортируется → `base-unbuildable`.

## M4. Мутация для сохранения

Кандидаты — узлы продуктовых функций, исполненные селекторами BEH в `|run`,
функции в порядке возрастания числа покрывающих тестов (по M1 всего набора),
ничья — по файл:строка. Операторы в фиксированном порядке (оператор, узел,
позиция): переворот сравнений, `and`↔`or`, снятие `not`, возврат → `None`,
`+`↔`-`, `True`↔`False`, строковый литерал исполненной строки → `"XX"`
(включая константные части `JoinedStr`; докстринги — никогда). Потолок 5 на
функцию; первое убийство по M2, подтверждённое чередованием чистый/мутант K = 2
с единогласием, → `confirmed`. Бюджет времени исчерпан до конца кандидатов →
`budget-exhausted`.

## M5. Замеры прототипа (i5/#171)

| замер | итог |
|---|---|
| 3 (узлы диффа, без рода) | 6/16 — FAIL |
| 4 (род BEH, полный откат файлов) | 15/16, BEH-12 — слабый тест; 170 с |
| 5 (частичный откат исполненных кусков) | 6/6 изменения; смешанный тест-читатель `unconfirmed`; 54 с |

Оговорка замера 5: частичный откат может дать несогласованный, но импортируемый
код; безопасно, потому что падение засчитывается только по M2.
