# Приложение к заявке spec-runner: механизм измерения `criteria-closure/v1`

Дата: 2026-09-28. Статус: **предложение соседу**, не норма devtools. Основание —
спека `2026-09-28-bundle-criteria-oracle-design.md` §4 (гарантии контракта B).
Владелец механизма — spec-runner: он вправе реализовать гарантии иначе, если
ответ несёт наблюдаемые поля §4.2 спеки и выполняет гарантии §4.1. devtools
проверяет только контракт.

Ниже — одна реализация, согласованная с владельцем экосистемы в сессии
2026-09-28 после трёх кругов локального ревью (классы: подмена измерителя,
причинность, окружение).

## M0. Окружение

Свежий клон репо-владельца на `product_sha`; `uv sync --frozen` из клона. Общий
кэш uv — намеренно: `--frozen` фиксирует lock, кэш лишь ускоряет.
`PYTEST_ADDOPTS` и прочие `PYTEST_*` вызова очищаются; конфигурация pytest репо —
часть продукта. Происхождение: каждый пакет продуктовых корней импортируется из
**продуктовых корней клона** (не из `.venv` клона и не из основного чекаута),
иначе `error: foreign-import`.

Продуктовые корни — исходные файлы, которым соответствуют файлы колеса,
собранного на `product_sha`: отображение через `RECORD` колеса по совпадению
sha256 с файлами дерева; файл колеса без пары (сгенерированный) —
`error: product-roots-unknown`.

## M1. Защищённое множество — из измерения, не из имён

После сбора (M2) защищены:

- файлы, в которых определены собранные элементы (`item.path`);
- все `conftest.py` дерева;
- модули всех плагинов, зарегистрированных в `config.pluginmanager` на момент
  сбора (`__file__`), включая `pytest_plugins`, `-p` и точки входа;
- все модули пакетов, содержащих собранный тестовый файл или conftest.

Патч, задевающий защищённый файл или файл вне продуктовых корней, — отказ до
применения (`control-out-of-roots`); sha256 защищённого множества сверяется до и
после `git apply`. Элементы, не являющиеся Python-функцией или методом
(`DoctestItem`, элементы собственных коллекторов), токенов не получают.
`protected_set_sha256` — в ответ.

## M2. Сбор

`pytest --collect-only` всего набора, без фильтров от закрытия. Пустая
коллекция или ошибка — ошибка уровня ответа (код 3). Селектор → определение
(файл + qualname) → токены по §1.4 спеки.

## M3. Протокол причинности

1. Каждый прогон node ID в обеих половинах — на свежем дереве (сброс tracked,
   index, untracked и кэшей внутри клона).
2. Чистая половина: каждый node ID множества BEH — фаза `call` `passed`.
3. Патч без изменения хотя бы одного AST-узла продуктового Python-модуля
   (только комментарии/пробелы) — `control-no-op`.
4. Половина с патчем: каждый node ID; для каждого `call: failed` — чередование
   чистый → с патчем K раз (K = 2). `confirmed` только если все чистые прогоны
   `passed` и все прогоны с патчем этого node ID `failed` в фазе `call`; иначе
   `nondeterministic`.
5. Ошибка сбора/импорта под патчем, падение `setup`/`teardown` —
   `control-not-failing`; таймаут, падение раннера — `error: runner`.

## M4. Отображение на ответ

Поля §4.2 спеки: `k_runs`, `protected_set_sha256`, по каждому селектору — исходы
всех прогонов с фазой, по контролю — путь и blob-хэш патча из `product_sha`,
`environment` (lock-хэш, версия Python, список плагинов pytest).
