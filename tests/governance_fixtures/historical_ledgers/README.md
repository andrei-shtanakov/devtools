# Исторические леджеры — фикстуры приёмки S13

Сняты с РЕАЛЬНЫХ записей `out/governance-runs` (приёмка §7.4), а не
сочинены: живая проверка умирает вместе с сессией, фикстура переживает.
Заменены только абсолютные пути машины — они не свойство класса.

| каталог | источник | класс |
|---|---|---|
| `legacy-completed` | `WS-dispatcher-229-7ed609` | прежний путь, завершён |
| `legacy-merged-unverified` | `WS-SMOKE-001-a1` | прежний путь, терминальный `merged_unverified` |
| `legacy-verify-child` | `WS-SMOKE-001-a1-v1` | verification-потомок того же цикла |
| `waves-completed` | `i5-traceless-noop-after-abandon-20260923-3e0ea3` | волновой, завершён |

Потомок взят вместе с родителем намеренно: без него WS-lock судит о
родителе иначе, и фикстура проверяла бы не ту ветку решения.
