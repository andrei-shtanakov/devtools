# Герметичность и цена прогона: BEH-18

Материалы TASK-003 (DT-03). Задача `type: verify` — ничего не меняет в
поставке, только предъявляет два замера.

Машина: macOS 26.7 (Darwin 25.6.0, arm64), Python 3.13.7 (`.venv`, тот же
интерпретатор на обоих деревьях — зависимости между ДО и ПОСЛЕ не менялись:
`git diff 6186164 5077c8c -- pyproject.toml uv.lock` пуст). Момент снятия
финальной пары замеров — между `2026-09-28T12:41:19Z` и
`2026-09-28T12:42:23Z` (окно между соседними проверками часов сессии).

## Условие «без сети»

Герметичность предъявлена условиями прогона, а не утверждением (**DEL-38**):
оба финальных прогона выполнены под `sandbox-exec` с профилем, безусловно
запрещающим сетевые операции процессу и его потомкам —

```
(version 1)
(deny default)
(allow file-read* file-write* file-write-create file-write-data process-fork process-exec sysctl-read mach-lookup)
(deny network*)
```

— и в ТОЙ ЖЕ обёртке, непосредственно перед прогоном pytest, сетевой канарейкой:
`curl -s -m 3 https://1.1.1.1`. На обоих деревьях канарейка дала
`http_code=000 curl_exit=7` (отказ соединения — сеть недоступна процессу),
после чего тем же вызовом `sandbox-exec` шёл прогон файла тестов. Зелёный
прогон в этих условиях отличим от прогона, сходившего наружу успешно: сеть
не «предположительно отсутствует», а фактически недоступна на уровне,
который прервал бы любой сокет-вызов.

## Деревья

- **ДО правки** (в собственном составе файла, новых сценариев там нет):
  коммит `6186164b827675d03ffa292950e5f81402362d54` — последний перед
  `6fd3e25` (TASK-001), которая первой в этой теме тронула
  `tests/test_governance_task_bridge.py`. Снято в отдельном `git worktree`,
  детач на этом SHA; `git status --short` в момент замера — пусто по
  отслеживаемым файлам (единственная запись — untracked `.venv`, символическая
  ссылка на общий венв, разделяемый обоими деревьями, т.к. зависимости не
  расходятся; предмета замера — `tests/`, `governance/` — она не касается).
- **ПОСЛЕ** (в полном составе): коммит
  `5077c8c8eb8e58ffe4978ec935161e042a5482a5` (`Merge task/task-002`, голова
  ветки `task/task-003` на момент снятия). Снято аналогично — отдельный
  `git worktree`, детач на этом SHA, `git status --short` пуст по
  отслеживаемым файлам.

Обе величины ниже названы вместе со своим деревом; замер без названного
дерева в материал не идёт (**DEL-39**) — черновые прогоны из общей рабочей
копии (не detached-worktree, где заведомо чисто) в этот документ не попали.

## Величины

Команда на обоих деревьях: `.venv/bin/python -m pytest
tests/test_governance_task_bridge.py --tb=short -q`, обёрнута
`sandbox-exec -f no-net.sb`, время — `/usr/bin/time -p` вокруг того же
вызова, что и канарейка.

### ДО правки — `6186164`

```
network canary: http_code=000 curl_exit=7
---
406 passed, 2 skipped in 4.31s
real 4.44
```

### ПОСЛЕ — `5077c8c`

```
network canary: http_code=000 curl_exit=7
---
427 passed, 2 skipped in 4.80s
real 4.90
```

Оба прогона зелёные (**DEL-38**). Собрано элементов: ДО — 408 (406 passed +
2 skipped), ПОСЛЕ — 429 (427 passed + 2 skipped); прирост — 21 собранный
элемент, что и есть новые сценарии/параметризации темы (BEH-01…BEH-21 за
вычетом BEH-06 и BEH-11 — те не постоянные сценарии, а временные мутации
TASK-002, снятые после прогона, и в дереве не живут).

## Разность и порог

Число pytest (`... in Ns`) — величина самого прогона файла, без обвязки
`time`/`sandbox-exec`; она и сравнивается с целью **NFR-02**
(«прогон файла тестов не растёт более чем на секунду»):

```
после  4.80s
до     4.31s
-------------
дельта 0.49s
```

`0.49s < 1s` — порог **NFR-02.Target** соблюдён (**DEL-37**, **AC-16**).

## Новые сценарии на дереве ДО правки — не предмет этого материала

Прогона новых сценариев на дереве `6186164` в этом документе нет и он не
требуется (**DEL-40**): там они обязаны краснеть по построению (это и
предъявляет TASK-001 — BEH-02, обе половины BEH-10 красны на нетронутом
дереве), а зелёный на дефектном дереве означал бы, что сценарии ничего не
проверяют. Величина «ДО» выше снята на составе файла БЕЗ новых сценариев
(406 прежних тестов), что и требует BEH-18 буквально («на дереве ДО правки в
его собственном составе»).

## Воспроизведение

```
$ git worktree add --detach /tmp/wt-before 6186164b827675d03ffa292950e5f81402362d54
$ git worktree add --detach /tmp/wt-after  5077c8c8eb8e58ffe4978ec935161e042a5482a5
$ # в каждом: символическая ссылка .venv -> общий венв (зависимости идентичны)
$ sandbox-exec -f no-net.sb sh -c '
    curl -s -m 3 https://1.1.1.1 -o /dev/null -w "network canary: http_code=%{http_code} curl_exit=%{exitcode}\n";
    .venv/bin/python -m pytest tests/test_governance_task_bridge.py --tb=short -q
  '
```

Рабочие worktree'я, использованные для замера, удалены после записи этого
файла — предмет замера (коммиты) в репозитории остаётся, черновые копии
дерева не являются сдаточным материалом.
