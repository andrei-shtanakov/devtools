## BEH-11: пустой докстринг проверку не проходит

Обе единицы, названные BEH-10, мутировались по одной: докстринг опустошён
(заменён на строку из одного пробела — буквальная пустота `""""""`
конфликтует с синтаксисом, поэтому взят минимальный непустой пробельный
литерал, который `_normalized_doc` (склейка пробельных последовательностей в
один + снятие обратных кавычек) нормализует в пустую строку).

### Мутация A — докстринг `SupersedeResult` опустошён

**Подменялось.** `class SupersedeResult:` — весь докстринг (23 строки,
описание `kind`) заменён на:

```python
class SupersedeResult:
    """ """  # MUTATION-BEH-11-A
```

**Прогонялось.** `uv run pytest tests/test_governance_task_bridge.py --tb=no -q`.

**Покраснело.** 1 упавший из 429 (426 passed, 2 skipped, 1 failed in 4.72s):

- `test_supersede_result_docstring_is_honest_about_noop`

Наблюдение, зафиксированное честно (не то, что ожидалось буквально, но
требование при этом выполняется по существу): `@dataclass` в Python 3.13
не считает докстринг из одного пробела «уже заданным» и подменяет
`__doc__` автосгенерированной сигнатурой конструктора. Упавший assert:

```
doc = _normalized_doc(tb.SupersedeResult)
assert _S_FORBIDDEN_DOC not in doc
assert _S_REQUIRED_DOC in doc
E   assert 'реконсиляции §I3' in
      'SupersedeResult(kind: "Literal[\'delivered\', \'returned\', \'noop\']", pr: \'int | None\' = None)'
```

`_S_REQUIRED_DOC` («реконсиляции §I3») в автосгенерированной сигнатуре
отсутствует, как и в буквально пустой строке — assert падает по той же
причине, которую проверяет BEH-11 (обязательная подстрока не найдена),
независимо от того, что именно вернул `__doc__` при опустошении.
Механизм подмены дataclass'ом — деталь конкретной версии Python, а не
требование темы; сценарий чувствителен к мутации в любом случае.

Реверт — возврат исходного 23-строчного докстринга; `git diff
governance/task_bridge.py` после реверта пуст (проверено — см. ниже).

   закрытый перечень запрещённых подстрок отсутствует в выводе, прочитанном

   красит другой тест автоматически, что и требует BEH-08 отдельно от

3. **Докстринг `SupersedeResult`** — правдивость закрыта зелёным
   **BEH-10** (половина 1: `test_supersede_result_docstring_is_honest_about_noop`).

зелёным сценарием И (для мест 1 и 3/4) с мутацией, доказавшей, что зелень
